## 4. One honest incident: `dsh web --help` tried to write the live profile

While finding out why `--profile` was rejected, one command was run from this session without
`DSH_HOME` pointing at the clone:

```
$ dsh web --help
Error: EROFS: read-only file system, open '/home/fish/.dsh/profiles/web/cordis.yml'
    at prepareProfile (.../profile-boot-QhDEDXsF.js:221:2)
```

It **failed** on the read-only mount before writing anything, and the mtimes above prove the file
was not touched. The cause: this session's shell already exports `DSH_HOME=~/.dsh` and
`DSH_PROFILE=web`. Every later invocation passed `env -u DSH_PROFILE -u DSH_PROFILE_DIR
DSH_HOME=<clone>`. Recorded here rather than left out, because a command was run that was not
scoped to the clone.
